Навчитися працювати з основними тегами: заголовки, абзаци, списки, блоки, рядки. Ознайомитися з тегами форматування тексту та створення гіперпосилань. Розвивати практичні навички створення простих веб-сторінок. Короткі теоретичні відомості HTML (HyperText Markup Language) — це мова розмітки, що визначає структуру веб-сторінки. Вона дозволяє браузеру розпізнати, які елементи є заголовками, абзацами, списками, посиланнями, а також як відображати текст. Основні теги HTML Структурні теги: — кореневий елемент документа; — метаінформація документа; — вміст сторінки, який бачить користувач; — назва сторінки, що відображається у вкладці браузера. Теги заголовків і абзаців: <h1> … <h6> — заголовки різних рівнів; <p> — абзац тексту; <div> — блоковий контейнер для групування елементів; <span> — рядковий контейнер для форматування частини тексту. Списки: <ul> — маркірований список; <ol> — нумерований список; <li> — елемент списку. Гіперпосилання: <a href="URL">Текст посилання</a> — створення текстового гіперпосилання; Атрибут target="_blank" відкриває посилання у новій вкладці; Можна робити посилання на інші сторінки сайту або на електронну пошту (mailto:). Теги форматування тексту HTML надає інструменти для візуального та семантичного форматування: Тег Опис Приклад <b> Жирний текст (декоративно) <b>Жирний</b> <strong> Важливий текст (семантика) <strong>Важливе</strong> <i> Курсив <i>Курсив</i> <em> Акцент на слові (семантика) <em>Акцент</em> <u> Підкреслений текст <u>Підкреслений</u> <mark> Виділення тексту <mark>Виділений</mark> <small> Зменшений шрифт <small>Дрібний текст</small> Примітка: Для сучасних сайтів семантичні теги (<strong>, <em>) більш рекомендовані, оскільки вони несуть значення для SEO та доступності.
